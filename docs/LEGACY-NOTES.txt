SVG ICONS - Assignment Cover Generator edition, extended for Byabsayee
(started from the Online Store icon set; extended and repaired for these projects)

ui/     line icons, 24x24 grid, stroke="currentColor" (inherits text colour), stroke-width 2, round caps/joins
social/ brand glyphs, filled with currentColor (google.svg keeps its official colours; signal.svg uses a 160x160 viewBox; github.svg uses a 16x16 viewBox;
        dribbble.svg and stackoverflow.svg are drawn as line icons like the ui/ set)
other/  project-specific artwork (store favicon + image placeholder, these have fixed colours)

Total: 231 icons (216 ui + 15 social) + 2 other.

Resize: change width/height on the <svg> or size it in CSS. Recolour: set `color` on the element or parent.
In the Assignment Cover Generator they are inlined with  <?php echo \App\Icon::svg('name'); ?>  (see src/Icon.php).
In Byabsayee they are inlined with  <?= icon('name') ?>  (app/Helpers/Icon.php) and  Icons.svg('name')  in JavaScript.
To add an icon to Byabsayee: put NAME.svg in public/icons/ui/ (or social/) and run  php bin/build-icons.php
